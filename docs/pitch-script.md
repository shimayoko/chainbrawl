# ChainBrawl — 1-minute pitch script

**0:00-0:12**

Most blockchain games only put the shop on-chain. The actual gameplay runs on a centralized server. Players can't verify anything.

> ほとんどのブロックチェーンゲームは、ショップだけをオンチェーンにしています。実際のゲームプレイは中央集権的なサーバーで動いています。プレイヤーは何も検証できません。

**0:12-0:28**

ChainBrawl is different. We put the entire battle logic on-chain, on Solana. Every fight is computed and verified by a program, not a server.

> ChainBrawlは違います。私たちは戦闘ロジック全体をSolana上のオンチェーンに置きました。すべての戦いはサーバーではなくプログラムによって計算され、検証されます。

**0:28-0:42**

Players mint a fighter NFT with on-chain stats. They stake tokens, enter a match, and Switchboard VRF provides fair randomness for combat.

> プレイヤーはオンチェーンのステータスを持つファイターNFTをミントします。トークンをステークし、試合に参加すると、Switchboard VRFが公平なランダム性を提供します。

**0:42-0:55**

Outcomes are deterministic and replayable. You can trust the result because you can verify it yourself, on-chain.

> 結果は決定論的で、リプレイ可能です。自分自身でオンチェーン上で検証できるので、結果を信頼できます。

**0:55-1:00**

ChainBrawl: real PvP, real ownership, fully on-chain.

> ChainBrawl：本物のPvP、本物の所有権、完全オンチェーン。
